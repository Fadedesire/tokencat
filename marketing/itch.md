## Description (EN)

TokenCat is a tiny desktop app that shows how much of your Claude subscription limits you've
used — the 5-hour window and the week — and when they reset. Live, right on your desktop.

- Sign in once in a built-in claude.ai window — no API keys.
- Floating panel, Windows taskbar widget or macOS menu bar.
- Notifications at 80 % / 100 % and when the limit resets.
- A pixel cat that gets worried when you're close to the limit, plus a cat fact of the day.
- "Early start": plan your 5-hour window so it resets mid-workday.
- 9 languages, ~100 MB RAM, a few MB on disk, updates itself.

**Privacy.** Your session stays in Windows Credential Manager / macOS Keychain and is sent
only to claude.ai. No analytics, no telemetry. Open source (MIT):
https://github.com/Fadedesire/tokencat

The app isn't code-signed yet, so Windows/macOS will warn on first launch —
[how to open it](https://github.com/Fadedesire/tokencat/blob/main/docs/INSTALL.md).

Free forever. If it helps — [buy the cat a coffee on Ko-fi](DONATE_LINK) ☕

## Описание (RU)

TokenCat — маленькая программа для Windows и macOS: в реальном времени показывает, сколько
израсходовано из 5-часового и недельного лимита подписки Claude и когда сброс.

- Вход один раз во встроенном окне claude.ai, без ключей.
- Плавающая панель, виджет в панели задач Windows или строка меню macOS.
- Уведомления на 80 % / 100 % и при сбросе.
- Пиксельный котик: волнуется у лимита и рассказывает котофакт дня.
- «Ранний старт»: сброс 5-часового окна посреди рабочего дня.
- 9 языков, ~100 МБ памяти, обновляется сама.

Сессия хранится в системном хранилище и уходит только на claude.ai. Без аналитики.
Открытый код (MIT). Бесплатно; поддержать котика — [Ko-fi](DONATE_LINK).
