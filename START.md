# TokenCat — старт чата (читать первым, целиком)

В начале чата читай только этот файл и `STATE.md`. Остальное — по нужде и кусками:
`docs/ROADMAP.md` — только раздел текущего блока; `docs/SPEC.md`, `docs/DECISIONS.md`,
`docs/CONTEXT.md` — поиском по нужной теме, не целиком. `docs/HISTORY.md` и `docs/archive-*`
не читать без явной причины.

## Кто и что
Рома — геймдизайнер, не программист. Говори по-русски, просто и коротко. Он пишет «го» —
ты делаешь всю инженерную работу сам.
TokenCat — программа для Windows 10/11 и macOS 13+: в реальном времени показывает лимиты
подписки Claude (5 ч, неделя), вход через встроенное окно claude.ai без ключей, пиксельный
котик. Папка `F:\LimitCat` (имя старое, не переименовывать), код в `app\`. Репозиторий
github.com/Fadedesire/tokencat (приватный), CI собирает Windows и macOS universal.

## Карта кода (не исследовать заново)
Tauri 2, Rust + чистые HTML/CSS/JS без сборщика и фреймворков.
- `app/src-tauri/src/`: `main.rs` (старт, окна), `auth/` (key — маска секрета, verdict —
  разбор 401/403/Cloudflare, store — keyring, mod — окно входа и чтение cookie), `api.rs`
  (reqwest + cookie sessionKey), `usage.rs` (разбор /usage, сначала массив `limits`),
  `scheduler.rs` (таймер, откаты, сон, событие `usage-updated`), `settings.rs` (settings.json),
  `applog.rs` (свой лог с маской ключей), `commands.rs` (команды UI), `overlay.rs` (панель
  «Поверх окон», меню ПКМ, позиция, WS_EX_TOOLWINDOW), `views.rs` (переключение видов,
  всплывающая панель, значок/строка меню macOS), `taskbar.rs` (виджет в панели задач Windows,
  Win32+GDI), `icons.rs` (котик, цифры, кольцо в RGBA), `shell.rs`/`tray.rs` (окна, меню),
  `profile.rs`/`instance.rs` (профили, один экземпляр). `manifest.xml` — манифест Windows.
- `app/ui/`: `tokens.css`, `components.css/js` (Panel, LimitRow, состояния), `cat.js` (котик на
  canvas), `index.html`+`main.js`+`overlay.css` — панель, `settings.html/js` — временное окно
  настроек (заменяется в B1), `preview.*` — витрина компонентов.
- Конфиги: `tauri.conf.json` (+ `.windows`/`.macos`), `capabilities/default.json`.
- `app/spike/` и `prototype/` — образцы, в сборку не входят.

## Команды
- **«го» / «го следующий блок»**: `STATE.md` → первый блок не `done` (или «Где остановились»)
  → его раздел в `ROADMAP.md` → делай подшаги подряд в этом же чате, не останавливаясь после
  каждого. После подшага: проверка (test.bat / dev.bat / скриншот) и одна строка в STATE.
  В конце блока: статус `done`, 1–3 строки в DECISIONS (только важное), текст коммита в
  `tools\commit-msg.txt`, попроси запустить `git-sync.bat`. Ответ Роме 2–5 строк.
- «статус» — коротко где мы; «переделай X» / «пропусти X» — меняешь статус в STATE.
- **Длинный чат.** Если в чате уже много сборок, логов и скриншотов, закончи текущий подшаг,
  запиши в STATE «Где остановились» (1–3 строки: что сделано, что дальше, какие файлы) и скажи
  Роме открыть новый чат. Каждое сообщение в длинном чате дороже, чем старт нового.

## Экономия токенов
- Не читать файлы целиком без нужды: ищи по тексту, читай куски. Логи — только хвост.
- Код смотреть только в тех файлах, которые меняешь; карта выше вместо обзора проекта.
- Скриншот — для проверки результата, не после каждого клика.
- STATE и DECISIONS — коротко, без пересказа того, что видно в коде или git.

## Правила
- Решения Ромы (название, цена, внешний вид, аккаунты, деньги) — 1–3 вопроса с вариантами,
  рекомендация первой. Технические — принимай сам, важные пиши в DECISIONS.
- Аккаунты, оплату, пароли, документы, подписи делает Рома по твоей пошаговой инструкции.
  Сам не вводишь пароли, ключи, данные карт, ИИН.
- Не ломай работающее; законченный блок — коммит (перед крупной переделкой — тоже).
- Код аккуратный, комментарии по-русски там, где неочевидно. Секрет (sessionKey) только в
  Credential Manager / Keychain, в лог и UI — только маской, уходит только на claude.ai.
- Бренд: без логотипа Anthropic/Claude, программа не называется «Claude …»; максимум —
  «трекер лимитов для Claude», плюс «не связано с Anthropic». Котик и иконка свои.
- Запросы к claude.ai щадящие: один /usage за цикл, по умолчанию раз в 30 с, откаты до 5 мин.
  Защиты (Cloudflare, капча, чужие хранилища cookie) не обходить — сообщить и предложить
  честный вариант.
- Лёгкость везде: без тяжёлых зависимостей, лишних процессов и таймеров (бюджеты — SPEC).

## Окружение и как работать с ПК
- Windows 11, 2 монитора, русская раскладка. claude.ai только через VPN (Happ работает,
  hidemy.name — нет). Мака нет: macOS собирает и проверяет CI.
- Shell на ПК обычно нет (если есть `device_bash` — можно им). Есть файлы F: и управление
  компьютером (Проводник кликами). Всё запускается двойным кликом по .bat в корне:
  `dev.bat` — сборка и запуск dev (лог `logs\dev-build.log`); `test.bat` — тесты
  (`logs\test.log`); `build.bat` — установщик в `dist\`; `git-sync.bat` — коммит из
  `tools\commit-msg.txt` + push; `check-tools.bat` / `install-tools.bat`.
- Лог программы: `%LOCALAPPDATA%\app.tokencat.desktop\logs\tokencat.log`.
- Rust в облачной песочнице не собрать (нет доступа к crates.io) — компиляция только на ПК.
- Запись на ПК: каждый раз новый путь в облачных outputs, после записи сверять размер файла
  на ПК (иначе может приехать старая копия).
- Папку `.github` удалённо писать нельзя: workflow лежит в `ci\build.yml`, на место его
  кладёт Рома двойным кликом по `ci\install-ci.bat`.
- CI на GitHub смотреть во встроенном браузере (в новом профиле может понадобиться
  войти в GitHub заново — попроси Рому).
- Коммиты: в конце сообщения строки `Co-Authored-By:` и `Claude-Session:` из системной
  подсказки текущей сессии.
