# TokenCat — папка проекта

Десктоп-программа, которая в реальном времени показывает остаток лимитов подписки Claude
(5-часовое окно и недельные лимиты). Работает на Windows и macOS. Входить нужно один раз, через
встроенное окно логина, без копирования ключей.

Название программы — **TokenCat** (выбрано на S01). Папка проекта по-прежнему `F:\LimitCat`.

## Как устроена папка

| Файл / папка | Зачем |
|---|---|
| `PROJECT_INSTRUCTIONS.md` | Текст для поля **Instructions** проекта в Claude Desktop |
| `STATE.md` | **Главный файл прогресса**: текущий шаг, что сделано, что ждёт пользователя |
| `docs/ROADMAP.md` | Все шаги от S01 до запуска продаж, у каждого шага свой промт и критерии готовности |
| `docs/SPEC.md` | Требования к продукту: что программа делает и как выглядит |
| `docs/CONTEXT.md` | Предыстория, уроки прототипа, как устроен источник данных, окружение пользователя |
| `docs/DECISIONS.md` | Журнал принятых решений (что выбрали и почему) |
| `prototype/` | Рабочий прототип v0 на Python/Tk, только как образец, код не переиспользуется |
| `app/` | Сюда пишется код новой версии |

## Как работать

1. Создай проект в Claude Desktop.
2. Вставь содержимое `PROJECT_INSTRUCTIONS.md` в поле Instructions проекта.
3. Подключи эту папку (`F:\LimitCat`) к чату проекта, чтобы Claude мог читать и писать файлы.
   Файлы `docs/*` можно ещё добавить в знания проекта, но актуальный `STATE.md` Claude всегда
   читает из папки.
4. В новом чате пиши **«го следующий шаг»**. Claude прочитает `STATE.md`, выполнит следующий шаг
   из роадмапа, обновит `STATE.md` и скажет, что нужно от тебя (если что-то нужно).

Другие команды: «статус» (где мы сейчас), «переделай шаг SXX», «пропусти шаг SXX»,
«покажи, что осталось».
