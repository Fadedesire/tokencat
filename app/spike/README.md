# Спайк S02 — вход и данные

Минимальное приложение на Tauri 2. Проверяет, что:
1. в своём окне `claude.ai/login` можно войти как обычно (Google или почта);
2. программа сама читает cookie `sessionKey` из своего webview — ключи копировать не нужно;
3. лимиты приходят двумя способами: **A** — нативный клиент (reqwest) с cookie,
   **B** — `fetch()` внутри скрытого окна claude.ai.

## Запуск
1. Один раз: `F:\LimitCat\install-tools.bat` (Rust + Build Tools + Node + Git).
2. Двойной клик `run-spike.bat`. Первая сборка 3–10 минут.
3. В окне спайка «1. Войти» → войти в открывшемся окне → программа сама спрячет окно и
   запросит лимиты обоими способами.
4. Результат сохраняется в `spike-report.json` (без cookie, только статусы и проценты).

VPN (Happ) должен быть включён: claude.ai доступен только через него.

Код — `src-tauri/src/main.rs`. Окну claude.ai доступ к IPC приложения не дан
(capability только для локального окна `main`); данные из него забираются через
`eval_with_callback`.
