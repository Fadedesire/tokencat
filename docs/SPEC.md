# Спецификация TokenCat (v1)

## Суть
Показывает в реальном времени, сколько лимитов подписки Claude израсходовано и когда сброс.
Windows 10/11 и macOS 13+. Запуск за минуту, без ввода ключей.

## Онбординг (первый запуск)
ОС → выбор вида большими карточками с превью (Windows: «Поверх окон» / «В панели задач»;
macOS: «Поверх окон» / «В строке меню») → «Войти в Claude» → встроенное окно claude.ai,
после входа закрывается само, сразу лимиты → «Запускать с системой» (вкл. по умолчанию).
Вид потом меняется в настройках.

## Виды
1. **Поверх окон** (обе ОС) — сделан в S07: тёмная панель со скруглениями, шапка (название,
   точка статуса, время обновления), строки «5 ч», «Неделя», при наличии «Sonnet»/«Opus»
   (полоска, процент, время до сброса), котик на разделителе шапки. Перетаскивание, позиция
   с учётом мониторов, поверх окон (переключаемо), двойной клик — обновить, ПКМ — меню.
   Опционально: компактный режим в одну строку, прозрачность.
2. **В панели задач** (Windows): компактный виджет у «Пуска» или у трея, две мини-полоски с
   процентами, котик по желанию; клик — всплывающая панель. Встраивание как у TrafficMonitor,
   запасной вариант — значок в трее с процентом. Учесть положение панели, автоскрытие, DPI,
   тему.
3. **Строка меню** (macOS): свой котик (шаблонное изображение) + `5ч 42% · Н 18%`
   (`5h 42% · W 18%`); цвет/значок по порогам; варианты: только 5 ч / 5 ч + неделя / только
   значок / кольцо. Клик — поповер с панелью и котиком. Без иконки в Dock.

## Внешний вид
Полоски: 0–49 % зелёный `#4cc38a`, 50–79 % жёлтый `#f5c542`, 80–100 % красный `#e5484d`.
Фон `#1f1e1d`, текст `#f0eee6`, вторичный `#8f8c84`, акцент `#d97757`. Светлая тема — после v1.
Котик: белый пиксельный, свой; дышит, моргает, хвост, ушко; спит без данных, встревожен при
80 %+; выключается в настройках.

## Данные
Источник — `CONTEXT.md`. Интервал по умолчанию 30 с (варианты 30 с / 1 / 2 / 5 мин), кнопка
«Обновить». Откаты при ошибках до 5 мин. Таймеры «до сброса» тикают локально. Уведомления
(выключаемые): 80 % и 100 % 5-часового лимита, сброс.

## Ошибки (текст для человека, детали — в лог)
Не вошли → «Войти». Сессия истекла → «Нужно войти заново». Cloudflare/регион → «claude.ai
недоступен из вашей сети. Проверьте VPN». Нет сети → «Нет соединения», повтор. Странный
ответ → «Не удалось прочитать данные» + «Открыть лог».

## Настройки
Вид; интервал; поверх окон; котик; автозапуск; язык; прокси HTTP/SOCKS (без пароля);
«Выйти»; продвинутое — ручной sessionKey; «Открыть лог»; версия и «Проверить обновления»;
«Поддержать проект», «Сообщить о проблеме».

## Нефункциональное
- Бюджеты лёгкости (проверка в B3, цифры в `docs/PERF.md`): установщик Win ≤ 10 МБ,
  portable ≤ 15 МБ, dmg ≤ 15 МБ; до окна с цифрами ≤ 1 с (кеш, потом обновление); RAM в
  простое ≤ 60 МБ вместе с WebView2 (если недостижимо — честная цифра в PERF.md); CPU в
  простое ≈ 0 %, с котиком < 1 %; сеть — один запрос за интервал + проверка обновлений.
- «Нажал — заработало»: без админа, без ручных сред (Python, .NET, VC++), без консолей,
  WebView2 на Win10 ставит установщик, повторный запуск показывает открытую программу.
- Один экземпляр на профиль. Секрет только в системном хранилище. Телеметрии нет.
- Несколько аккаунтов (B1): каждый аккаунт — свой профиль и своя копия программы со своим
  ключом и настройками; в шапке панели и в трее — имя из профиля claude.ai.
- Автообновление из GitHub Releases с подписью.
- 9 языков: RU, EN, ES, PT-BR, DE, FR, JA, KO, ZH-Hans; по умолчанию язык системы, иначе EN.
- «Не связано с Anthropic», свой бренд.

## Название и деньги
- **TokenCat**; в описании максимум «трекер лимитов для Claude».
- Программа целиком бесплатна, без урезаний. GitHub, лендинг, winget, Homebrew — бесплатно
  + «Поддержать». itch.io, Gumroad/Lemon Squeezy — «плати сколько хочешь» от 0 $
  (рекомендуемо 3 $). Microsoft Store (если будем) — 1,99 $. Pro (история, графики) — после v1.
- Донаты максимально просто: первым — прямой перевод на карту/по телефону (для своих стран,
  номер карты целиком не публиковать), платформы с верификацией — только где без них никак.

## Вне v1
Мобильные, Linux (после v1), все аккаунты в одной панели, история расхода и графики.
