## Продукт
- v0 — новая версия с нуля, прототип Python/Tk только образец (нет входа без ключей, панели
  задач, строки меню).
- S01 — название **TokenCat** (папку не переименовываем). Риск: Token Cat Limited (Nasdaq,
  тикер TC) — проверить товарный знак в классе ПО перед публикацией (B6).
- S01 — Mac: элемент строки меню «значок + 5h 95% · W 91%» со своим котиком, кольцо — опция.
- S01 — деньги гибридные: бесплатно + донаты (GitHub, winget, Homebrew, лендинг), «плати сколько
  хочешь» (itch.io, Gumroad/LS), платно только Microsoft Store. Жёсткий пейвол отклонён.
- S01 — 9 языков, по умолчанию язык системы, иначе EN.
- Интервал по умолчанию 30 с (решение Ромы, было 60), варианты 30 с / 1 / 2 / 5 мин;
  сохранённые настройки не перезаписываем.
- Бюджеты лёгкости в SPEC; RAM 60 МБ с WebView2 — амбициозно, при невозможности — реальная

## Стек и сборка
- S02 — Tauri 2. `cookies_for_url` отдаёт HttpOnly `sessionKey` на WebView2 и WKWebView; на
  Windows вызывать только из async-команды в отдельном потоке (иначе дедлок WebView2).
- S02 — запросы: основной — reqwest + cookie `sessionKey` (не держим живой webview → память,
  проще прокси); запасной — fetch в скрытом webview при 401/403 без Cloudflare или блоке
  Cloudflare (ещё не включён; нужен, если `__Host-sessionBinding` начнёт привязывать сессию).
  Electron не нужен.
- S03 — UI без сборщика: `frontendDist: ../ui`, Node только для Tauri CLI. dev.bat — `cargo
  build`, build.bat и CI — `npx tauri build`. Release: `opt-level="s"`, LTO, strip. NSIS для
  текущего пользователя (без админа), WebView2 загрузчиком; macOS universal .app + .dmg, ≥ 13.0.
- S03 — git через `git-sync.bat` (текст из `tools\commit-msg.txt`, адрес из
  `tools\remote.txt`, оба в .gitignore); CI-файл в `ci\build.yml`, ставит `ci\install-ci.bat`.
- CI: предупреждение «Node.js 20 deprecated» у actions/*@v4 — обновить мажорные версии при
  следующей правке build.yml.

## Вход и секреты
- S04 — окно `claude-login`: раз в секунду читаем cookie, новый `sessionKey` проверяем
  `/api/organizations`; 200 → keyring (сервис `app.tokencat.desktop`, учётка
  `tokencat-session`), окно закрываем. Отвергнутую cookie повторно не проверяем.
- S04 — «Выйти» = удалить ключ + `clear_all_browsing_data` (данные webview общие).
- S04 — «сессия истекла» только при 401 или 403 с JSON; 403/429/5xx с HTML/Cloudflare →
  «Проверьте VPN», ключ не трогаем.
- S04 — `SessionKey` печатается только маской; команды проверяют, что вызов из окон UI
  (`UI_LABELS`: main, settings), окну claude.ai IPC не даём; события через `emit_to`; в окне
  входа навигация только https. Ручной ключ: чистим `sessionKey=…;`, кавычки, переносы;
  сохраняем, только если claude.ai принял.

- 2026-10-29 — Несколько аккаунтов идут в v1 (B1, п. 9) через профили: отдельная копия
  программы на аккаунт, у профиля свои ключ, settings.json, папка WebView2 и позиция.
  Почему: дешевле, чем переделывать всю панель под список аккаунтов; одна панель на все
  аккаунты — после v1. Single-instance — по профилю. Имя аккаунта показываем, почту — нет.

- B1 — один экземпляр на профиль — свой (127.0.0.1 + `instance.port` в папке профиля), не
  tauri-plugin-single-instance: плагин привязан к identifier, т.е. одна копия на всю программу.
  Автозапуск — crate auto-launch напрямую (своя запись на профиль, `--profile`), уведомления —
  notify-rust напрямую (плагин подменяет window.Notification и в окне claude.ai).
- B1 — второй аккаунт входит «с чистого листа»: Windows — своя папка WebView2 окна входа
  (стираем перед входом и при выходе), macOS — incognito (data_store_identifier только с 14).
  Имя — `/api/account` (display_name → full_name), запасное — имя организации; раз в сутки.
- B1 — уведомления только по 5-часовому окну; «сброс» — лишь после 80 %+ (падение ниже 50 %),
  уровень хранится в settings.json, чтобы перезапуск не повторял.

- B1 — автозапуск включаем сразу при первом запуске профиля (решение Ромы), онбординг
  предлагает его включённым; «Добавить аккаунт» сначала открывает профиль, где ещё не входили.

- B2 — панель задач Windows: своё окно Win32 + GDI (не WebView), дочернее для `Shell_TrayWnd`,
  левее `TrayNotifyWnd`; поток с невидимым окном-хозяином ловит `TaskbarCreated`, тему, таймер
  1 с (место/DPI/автоскрытие). Фон — UpdateLayeredWindow с альфой 1/255: прозрачно, но клик по
  всей площади (с LWA_COLORKEY клики проваливались сквозь пустые места). Нужен свой манифест
  (compatibility Win8+, только ASCII — иначе ошибка 14001). 10 с без панели → запасной вид:
  проценты на значке трея.
- B2 — в видах «панель задач»/«строка меню» главное окно = всплывающая панель у виджета/значка,
  прячется при потере фокуса; повторный клик в течение 0,4 с после такого скрытия = «закрыть».
- B2 — macOS: элемент строки меню = значок трея Tauri (`set_title` + картинка из icons.rs).
  Цвет текста API не даёт, поэтому порог показывает котик: < 50 % шаблонный (под тему строки),
  50 %+ жёлтый/красный. Без Dock: `ActivationPolicy::Accessory` + `LSUIElement` в Info.plist.
  Проверка — сборка и тесты в CI; живой скриншот — у тестера с Маком (B5).

## Интерфейс
- S06 — чистый JS+CSS; `TokenCat.ui.Panel` получает снимок и сам решает, что показать (одна
  логика на все виды). В шапке вместо «звёздочки» прототипа (похожа на лого Claude) — надпись
  TokenCat, иконка — котик.
- S06 — котик на canvas, общий таймер 8 кадр/с, стоп при `document.hidden`, статичен при
  `prefers-reduced-motion`; клетка = round(px × devicePixelRatio), без сглаживания.
  Настроения: sleep — нет данных/не вошли, alert — любой лимит 80 %+.
- S07 — окно `main` = панель (index.html + main.js), временное окно `settings` до B1. Меню
  ПКМ нативное (tauri::menu): HTML-меню не влезло бы в окно 252 px.
- S07 — Alt+Tab: стиль WS_EX_TOOLWINDOW до показа окна (windows-sys 0.61, только Windows);
  `skipTaskbar` прячет лишь кнопку. На macOS для прозрачности `macOSPrivateApi` (в Mac App
  Store не идём).
- S07 — позиция: outer_position в физ. пикселях через 0,7 с после движения; при старте
  середина шапки и одна боковая точка должны быть на мониторе, иначе правый верхний угол
  основного с отступом 16 px. Размер окна задаёт JS (`overlay_fit`).
- S07 — `windows_subsystem = "windows"` всегда (кроме тестов): консоли нет и в dev, лог в файле.

- B2 — 30.10: панель влетела в панель задач → перетаскивание кончается сразу (поток
  watch_drag выходит); вытащить снова — новым нажатием на виджет.
- B10 — анимации без библиотек. Панель: CSS transform/opacity на #slot (main.js, overlay.css),
  масштаб ≤ 1 (окно = размер панели), fit() во время анимации не трогает размер окна. Залёт
  190 мс в точку панели ближе к панели задач, Rust ждёт FLY_IN_MS и прячет окно. Вылет —
  из точки хвата (FLY_FROM → payload panel-appear); старт с прозрачной панели прикрывает
  недорисованный WebView. Виджет: таймер 15 мс только на время анимации — «шлепок» 300 мс
  (сжатие картинки в push_alpha + волна полосок), переезд в ряду 140 мс ease-out.
  «Эффекты анимации» Windows выкл. → без анимаций (SPI_GETCLIENTAREAANIMATION / reduced-motion).

- B9 (30.10, решение Ромы) — ранний старт окна делает официальная запланированная задача
  Claude (облако, работает и с выключенным ПК), а не TokenCat: отправка сообщений скриптом
  через неофициальный чат-API — риск по правилам и блокировок. TokenCat даёт пошаговую
  инструкцию и по `resets_at` проверяет, что окно стартовало вовремя. Время задачи = желаемый
  сброс − 5 ч + 1 мин (по справке Anthropic сброс округляется до начала часа; по отзывам —
  может считаться от минуты; +1 мин даёт нужный час при любом правиле).
- B9 — котофакт дня берём из встроенной коллекции (без сети, переводится в B3), ответ Claude
  из чата не читаем.
- B9 (30.10, Рома) — ранний старт по умолчанию ВКЛ; в онбординге отдельный шаг: зачем,
  кому нужно, во сколько ставить сброс.
- B9 — проверка «сработало ли» по `resets_at` 5-часового окна: сброс в [час, час+60 мин) —
  ок; окно не начато через 15 мин после задачи — «не сработала»; иначе — «окно началось не
  от задачи». Реальный `resets_at` бывает не на начале часа (видели 12:39), т.е. окно, похоже,
  считается от минуты — +1 мин у задачи нужен. Расчёты в `ui/early.js` (чистый JS, тесты —
  `tools/test-ui.js` на Node в 5 часовых поясах, test.bat запускает их, если Node есть).
- B9 — свой планировщик запросов (п. 3 роадмапа) не делаем: запрос шлёт задача Claude.
  Котофакт — по номеру дня из `ui/catfacts.js`; в settings.json храним только день, когда
  облачко закрыли (`fact_hidden_day`). Облачко — внутри панели под шапкой (окно = размер панели).
- B3 — языки: один источник строк `app/locales/<язык>.json` (плоский «ключ → строка», `{имя}`
  для подстановок, `facts` — 60 котофактов на каждом языке). Rust зашивает файлы в exe
  (`i18n.rs`, include_str!) и берёт оттуда меню, уведомления, ошибки; окна получают словарь
  командой `i18n_get` (`ui/i18n.js`, страница скрыта, пока словарь не пришёл). Сменили язык —
  событие `lang-changed`, окна перезагружаются. «Как в системе» — crate sys-locale; pt → pt-BR,
  любой zh → zh-Hans, иначе EN. Лог программы остаётся по-русски (он для нас, не для UI).
  Тест `locales_complete` ловит пропущенные ключи и несовпадение подстановок.
- B3 — у JA/KO/ZH колонка «до сброса» шире (70 px вместо 52, `html:lang(..)`), иначе
  «3時間05分» не влезает. Время везде коротко («3ч 05м», «3h 05m», «6T 23h»), без склонений;
  интервал — «30 с / 1 мин», маска ключа — «(108)» без слова «символов».
- .bat писать только с CRLF: с LF cmd рвёт строки с кириллицей («'╤В╨╕╨╡' is not recognized»).
