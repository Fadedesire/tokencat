# Журнал решений

Формат: дата — решение — почему — какие были альтернативы. Новые записи дописываются вниз.

- **2026-10-29 — Делаем новую версию с нуля, прототип v0 только как образец.**
  Почему: Python/Tk не даёт нормального входа без ключей, панели задач Windows и строки меню
  macOS. Альтернатива: дорабатывать Tk-прототип (отклонено).

- **2026-10-29 — Вход через встроенное окно claude.ai, без чтения чужих хранилищ.**
  Почему: пользователю не нужно копировать ключи; не трогаем cookie браузеров и Claude
  Desktop (заблокированы и защищены, обходить нельзя). Альтернатива: ручной ввод
  sessionKey (оставлен запасным в «Продвинутом»).

- **2026-10-29 — Свой бренд, рабочее название LimitCat.**
  Почему: условия Anthropic запрещают использовать их имя и логотип в своих продуктах без
  разрешения. Финальное название — на S01.

- **2026-10-29 — Предварительный стек: Tauri 2 (Rust + TS), запасной — Electron.**
  Почему: маленькие сборки, нативный трей и строка меню, Rust для панели задач Windows,
  updater. Требует проверки доступа к cookie webview на S02.

- **2026-10-29 — Опрос по умолчанию раз в 60 с, с откатом.**
  Почему: бережём сервис и аккаунты пользователей, источник неофициальный.

- **2026-10-29 — Добавлен шаг S13 «Оптимизация» и бюджеты лёгкости в SPEC.**
  Почему: пользователь хочет, чтобы программа весила мало, стартовала быстро и работала
  «нажал — заработало». Шаги S13–S22 сдвинуты на +1 (стало S14–S23). Бюджет RAM 60 МБ
  с WebView2 — амбициозный, при невозможности фиксируем реальную цифру в PERF.md.

- **2026-10-29 — S01: название TokenCat.**
  Выбрал пользователь (варианты: LimitCat, TokenPaw, Quota Kitty, Meowter). Риск: на Nasdaq
  есть компания Token Cat Limited (тикер TC) — другая сфера, но перед публикацией (S19)
  проверить товарные знаки в классе ПО. Папку `F:\LimitCat` не переименовываем.

- **2026-10-29 — S01: «колесо» на Mac = элемент строки меню.**
  По скрину пользователя: значок + текст «5h 95% · W 91%» в верхней строке. Делаем так же,
  со своим котиком; кольцо — опция в настройках.

- **2026-10-29 — S01: гибридная модель денег.**
  Бесплатно + донаты там, где так принято (GitHub, winget, Homebrew, лендинг); «плати сколько
  хочешь» на itch.io и Gumroad/Lemon Squeezy; платно только в Microsoft Store. Почему:
  максимум площадок без жёсткого пейвола; платная копия при бесплатной на GitHub — обычная
  практика. Альтернатива «везде платно» отклонена: утилита на неофициальном источнике.

- **2026-10-29 — S01: 9 языков интерфейса.**
  RU, EN, ES, PT-BR, DE, FR, JA, KO, ZH-Hans; по умолчанию язык системы, иначе EN. На вес
  почти не влияет (файлы строк по несколько КБ).

- **2026-10-29 — S02: устройство спайка входа.**
  Tauri 2.4+ даёт `cookies_for_url` (возвращает и HttpOnly-cookie на WebView2 и WKWebView) —
  этим читаем `sessionKey` из своего окна входа. На Windows вызов только из async-команды в
  отдельном потоке (иначе дедлок WebView2). Окну claude.ai НЕ даём доступ к IPC приложения:
  результат fetch внутри него забираем через `eval_with_callback` с опросом. Окно входа при
  закрытии прячется, а не уничтожается (в нём живёт сессия для способа B). Сравниваем
  способ A (reqwest + cookie) и способ B (fetch в скрытом webview) — итоговый выбор после
  запуска на ПК пользователя через VPN. Electron пока не делаем: API Tauri для cookie есть.

- **2026-10-29 — S02 итог: стек Tauri 2, запросы — нативный клиент, запасной — webview.**
  Факты с ПК пользователя (Windows 11, WebView2 156, VPN Happ): `cookies_for_url` отдаёт
  HttpOnly `sessionKey`; оба способа дали 200 и одинаковые данные. Основной способ — reqwest
  с cookie `sessionKey`: не нужно держать живой webview (экономия памяти, бюджет из SPEC),
  проще планировщик и прокси. Окно claude.ai после входа закрываем полностью.
  Запасной способ — fetch в скрытом webview: включается, если нативный получил 401/403 без
  признаков Cloudflare или блок Cloudflare. Почему держим запасной: в cookie появились
  `__Host-sessionBinding*` — если сервис начнёт привязывать сессию к браузеру, нативный
  способ сломается, а webview — нет. Electron не нужен.

- **2026-10-29 — S03: UI без сборщика фронтенда, Node только для Tauri CLI.**
  `ui/` — чистые HTML/CSS/JS, отдаются Tauri напрямую (`frontendDist: ../ui`). Почему:
  лёгкость, нет npm-зависимостей в рантайме и шага сборки фронта. `dev.bat` собирает через
  `cargo build` (путь, проверенный в S02, работает без npm), `build.bat` и CI — через
  `npx tauri build` (нужен для установщика). Релиз-профиль: `opt-level="s"`, LTO, strip.
  Windows-установщик — NSIS, для текущего пользователя (без прав администратора), WebView2
  ставится загрузчиком. macOS — universal `.app` + `.dmg`, минимум 13.0.

- **2026-10-29 — S03: git через `git-sync.bat`, CI-файл через `ci\install-ci.bat`.**
  Shell на ПК у Claude нет, поэтому git-команды упакованы в bat: коммит берёт текст из
  `tools\commit-msg.txt`, адрес репозитория — из `tools\remote.txt` (оба в .gitignore).
  Папка `.github` защищена от записи удалёнными инструментами Claude — копирование
  workflow делает пользователь осознанно двойным кликом.

- **2026-10-29 — S04: как устроен вход.**
  Окно `claude-login` с https://claude.ai/login, раз в секунду читаем cookie своего webview
  (`cookies_for_url` в отдельном потоке). Новый `sessionKey` сразу проверяем запросом
  `/api/organizations`: 200 → ключ в Credential Manager/Keychain (crate `keyring` 3, сервис
  `app.tokencat.desktop`, учётка `tokencat-session`), окно закрываем. Старую cookie, которую
  API отверг, повторно не проверяем — ждём, пока она сменится. «Выйти» = удалить ключ из
  хранилища + `clear_all_browsing_data` (данные webview общие для всех окон). Почему не держим
  ключ в файле: требование SPEC. Альтернатива «сохранять без проверки» отклонена: можно
  сохранить мусор с незавершённого входа.

- **2026-10-29 — S04: «сессия истекла» только по ответу самого API.**
  401 или 403 с JSON → вход заново. 403/429/5xx со страницей Cloudflare или любой HTML →
  «Проверьте VPN», ключ не трогаем. Почему: урок прототипа — 403 почти всегда регион/VPN.

- **2026-10-29 — S04: защита секрета.**
  Тип `SessionKey` печатается только маской (Debug/Display), в UI уходит только маска. Команды
  приложения проверяют, что их вызвало главное окно, а не окно claude.ai (плюс capabilities
  только для `main`). События — `emit_to("main")`. В окне входа разрешена навигация только по
  https. Ручной ввод ключа принимает частые варианты копирования (`sessionKey=…;`, кавычки,
  переносы) и сохраняет ключ, только если claude.ai его принял.
