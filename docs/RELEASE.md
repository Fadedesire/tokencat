# Как выпустить версию (B4)

1. **Версия.** Claude поднимает `version` в трёх местах: `app/src-tauri/tauri.conf.json`,
   `app/src-tauri/Cargo.toml`, `app/package.json` (должны совпадать — иначе CI остановится).
2. **Что нового.** 1–5 строк в `ci/release-notes.md` (RU/EN). Этот текст увидят и на GitHub,
   и в окне обновления программы (первые 400 символов).
3. `git-sync.bat` — сохранить и отправить.
4. `tools\release.bat` — ставит тег `vX.Y.Z` и отправляет. На GitHub запускается
   **release** (≈15 мин): Windows-установщик, portable-zip, macOS dmg, файлы обновления,
   `latest.json`, SHA256SUMS — всё в **черновик** релиза.
5. GitHub → Releases → черновик: скачать, быстро проверить, **Publish release**.
   Только после публикации обновление прилетит пользователям (раз в сутки или по кнопке
   «Проверить»).

Если сборка упала — исправить, поднять версию (тег с тем же номером второй раз не ставится)
или удалить тег на GitHub и запустить заново.

## Ключи

- Подпись обновлений: приватный ключ `%USERPROFILE%\.tauri\tokencat-updater.key` (только на
  ПК Ромы и в секрете GitHub `TAURI_SIGNING_PRIVATE_KEY`), публичный — в `tauri.conf.json`.
  **Сделайте резервную копию ключа** (флешка / менеджер паролей): без него новые версии не
  смогут обновить старые.
- Подпись Windows-exe (SignPath) и Apple — пока нет, см. `docs/CODE_SIGNING.md`, DECISIONS.
