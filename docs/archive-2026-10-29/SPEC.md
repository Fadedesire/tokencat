# Спецификация продукта (v1)

## Цель
Программа, которая в реальном времени показывает, сколько лимитов подписки Claude израсходовано
и когда они сбросятся. Запускается за минуту, без ввода ключей. Работает на Windows 10/11 и
macOS 13+.

## Первый запуск (онбординг)
1. Программа определяет ОС.
2. Экран выбора вида (большие карточки с превью):
   - **Windows:** «Поверх окон» или «В панели задач».
   - **macOS:** «Поверх окон» или «В строке меню (кольцо)».
3. Экран входа: кнопка «Войти в Claude» → встроенное окно claude.ai → пользователь входит
   как обычно → окно закрывается само, программа сразу показывает лимиты.
4. Галочка «Запускать вместе с системой» (по умолчанию включена).
Выбор вида потом меняется в настройках.

## Виды отображения
### 1. Поверх окон (Windows и macOS)
Как в прототипе: тёмная панель со скруглениями, шапка (иконка, название, точка статуса, время
обновления), строки «5 ч», «Неделя» и, если есть, «Sonnet», «Opus»: полоска, процент
использования, время до сброса. Котик сидит на разделителе шапки. Перетаскивается мышью,
запоминает позицию (с учётом нескольких мониторов), всегда поверх окон (переключаемо),
двойной клик — обновить, ПКМ — меню. Опционально: компактный режим (одна строка) и прозрачность.

### 2. В панели задач (Windows)
Компактный виджет прямо на панели задач рядом с кнопкой «Пуск» или у области уведомлений.
Две мини-полоски с процентами, котик по желанию. Клик — всплывающая панель с подробностями,
как в виде «Поверх окон». Реализация выбирается на шаге S09: окно, встроенное в панель задач
(как у TrafficMonitor), с запасным вариантом «значок в трее с процентом + всплывающая панель»,
если встраивание недоступно. Учесть: панель задач слева/справа/сверху, автоскрытие, разные
DPI, тёмная/светлая тема Windows.

### 3. В строке меню (macOS)
Элемент в строке меню (верхняя полоса macOS, где часы, Wi-Fi, батарея, раскладка) — как у
программы с образца пользователя (скрин от 2026-10-29): маленький значок + текст
`5ч 42% · Н 18%` (в EN: `5h 42% · W 18%`). Значок — свой котик (шаблонное изображение,
перекрашивается под светлую/тёмную строку меню), не логотип Anthropic/Claude. Цвет/значок
может меняться по порогам (норм / 80%+ / 100%). В настройках: что показывать (только 5 ч,
5 ч + неделя, только значок) и вариант «кольцо» — круговой индикатор вместо текста.
Клик — поповер с подробностями (как «Поверх окон») и котиком. Иконки в Dock нет.

## Цвета полосок
- 0–49% — зелёный `#4cc38a`
- 50–79% — жёлтый `#f5c542`
- 80–100% — красный `#e5484d`
Фон `#1f1e1d`, текст `#f0eee6`, вторичный текст `#8f8c84`, акцент `#d97757`. Светлая тема —
по желанию, после v1.

## Котик
Белый пиксельный котик, свой (не персонаж и не чужой маскот). Idle-анимация: дыхание,
моргание, хвост, редкое дёргание ушком. Спрайт и логика кадров есть в
`prototype/claude_limits.pyw` (`CAT_HEAD`, `CAT_BODY`, `CAT_TAILS`, `cat_frame`). В v1 можно
добавить реакции: спит, когда данных нет; встревожен при 80%+. Котика можно выключить в
настройках.

## Данные и обновление
- Источник — см. `CONTEXT.md`. Интервал по умолчанию 30 с (решение пользователя), варианты 30/60/120/300 с,
  кнопка «Обновить сейчас». При 429 — экспоненциальный откат до 5 минут.
- Таймеры «до сброса» тикают локально каждую секунду или минуту, без запросов.
- Уведомления (опционально): при 80% и 100% 5-часового лимита и при его сбросе.

## Состояния и ошибки (понятные пользователю)
- Не выполнен вход → кнопка «Войти».
- Сессия истекла → «Нужно войти заново» + кнопка.
- Cloudflare/регион → «claude.ai недоступен из вашей сети. Проверьте VPN».
- Нет сети → «Нет соединения», повтор с откатом.
- Неожиданный ответ → «Не удалось прочитать данные» + ссылка «Открыть лог».

## Настройки
Вид отображения; интервал обновления; поверх окон вкл/выкл; котик вкл/выкл; автозапуск;
язык (9 языков, см. «Локализация»); прокси (HTTP/SOCKS, опционально); «Выйти из аккаунта»; продвинутое — ручной ввод
sessionKey; «Открыть лог»; версия и «Проверить обновления»; ссылки «Поддержать проект» и
«Сообщить о проблеме».

## Нефункциональные требования
- **Лёгкость и запуск** (бюджеты, проверяются на шаге S13, цифры в `docs/PERF.md`):
  - установщик Windows ≤ 10 МБ, portable-exe ≤ 15 МБ (dmg на macOS ≤ 15 МБ);
  - от двойного клика до окна с цифрами ≤ 1 с (последние данные из кеша, потом обновление);
  - RAM в простое ≤ 60 МБ суммарно со всеми процессами WebView2;
  - CPU в простое ≈ 0%, с анимацией котика < 1%; анимация на паузе, когда окно скрыто;
  - сеть: один запрос раз в интервал, без фоновых загрузок кроме проверки обновлений.
  - «Нажал — заработало»: без прав администратора, без ручной установки сред выполнения
    (Python, .NET, VC++), без консольных окон; WebView2 на Windows 10 ставится установщиком
    сам; повторный запуск показывает уже открытую программу.
- Один экземпляр программы одновременно.
- Секреты только в системном хранилище (Credential Manager / Keychain). Никакой телеметрии
  по умолчанию.
- Автообновление из GitHub Releases с подписью обновлений.
- Локализация: 9 языков — русский, английский, испанский, португальский (Бразилия),
  немецкий, французский, японский, корейский, китайский (упрощённый). По умолчанию — язык
  системы (если его нет в списке — английский), сменить можно в настройках.
- Неофициальность: «Не связано с Anthropic», свой бренд.

## Название и деньги
- Название: **TokenCat**. В описании максимум «трекер лимитов для Claude», плюс «не связано с
  Anthropic».
- Модель денег гибридная, по обычаям каждой площадки: программа целиком бесплатна, без
  урезанных функций.
  - GitHub Releases, лендинг, winget, Homebrew — бесплатно + кнопка «Поддержать» (Boosty/Ko-fi).
  - itch.io и Gumroad/Lemon Squeezy — «плати сколько хочешь», от 0 $, рекомендованная 3 $.
  - Microsoft Store (если будем публиковать) — платно, ориентир 1,99 $, как «покупка ради
    удобства и поддержки» (бесплатная версия остаётся на GitHub — так принято).
  - Платная Pro (история расхода, графики) — кандидат после v1, не раньше.
  - Пожелание пользователя (2026-10-29): где можно, принимать донаты максимально просто —
    прямым переводом на свою карту/по номеру телефона, без регистрации на платформах.
    На S20 сделать это первым способом в кнопке «Поддержать» (для своих стран), а площадки
    с верификацией (Boosty, Ko-fi, Gumroad, itch.io) подключать только там, где без них никак
    (иностранцы, оплата картами других стран). Номер карты целиком не публиковать — только
    ссылку на перевод или номер телефона, если банк так умеет.
