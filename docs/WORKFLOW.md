# Как устроена работа над TokenCat (для чатов с Claude)

Десктоп-программа для Windows и macOS: в реальном времени показывает остаток лимитов подписки
Claude (5-часовое окно и неделя). Вход один раз через встроенное окно, без копирования ключей.
Папка проекта — `F:\LimitCat` (старое рабочее имя).

## Файлы
| Файл | Зачем |
|---|---|
| `START.md` | **Вход для нового чата**: правила, карта кода, окружение, экономия токенов |
| `STATE.md` | Прогресс: текущий блок, что ждёт пользователя, где остановились |
| `docs/ROADMAP.md` | 8 блоков работы до запуска (блок = один чат) |
| `docs/SPEC.md` | Требования к продукту |
| `docs/CONTEXT.md` | Источник данных, грабли, риски |
| `docs/DECISIONS.md` | Принятые решения |
| `docs/HISTORY.md`, `docs/archive-*` | Подробная история и старые полные версии доков |
| `PROJECT_INSTRUCTIONS.md` | Короткий текст для поля Instructions проекта (необязательно) |
| `app/` | Код (Tauri 2) · `prototype/` — старый прототип-образец |

## Как начать чат (в любом профиле)
1. Подключи компьютер и папку `F:\LimitCat` к чату.
2. Напиши: **«Прочитай F:\LimitCat\START.md и STATE.md. Го.»**
Дальше достаточно писать «го». Другие команды: «статус», «переделай X», «пропусти X».
