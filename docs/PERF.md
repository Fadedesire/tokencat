# PERF — замеры лёгкости TokenCat (B3)

Как мерить: двойной клик `perf.bat` (релизная сборка + замеры, ~5 мин) → `logs\perf.txt`.
ПК Ромы: Windows 11 Pro, 16 ядер. Вид — «в панели задач» (панель WebView2 скрыта),
профиль по умолчанию, интервал 30 с. Release-профиль уже был: opt-level "s", lto,
codegen-units 1, strip, panic=abort.

## Что сделано (B3 п. 3)
- Кеш последних цифр (`cache.rs`, `last-usage.json` в папке профиля): панель открывается
  с цифрами серыми («устаревшие»), свежие приходят следом. Окна, чей сброс уже прошёл,
  показываются как 0 %. Кеш старше 8 дней не берём. Файл пишется, только когда цифры поменялись.
- Флаги WebView2 для всех окон (`shell::BROWSER_ARGS`): `--disable-gpu`,
  `--disable-background-networking`, `--disable-component-update` (+ флаги Tauri по умолчанию).
  Главный выигрыш по памяти: −60 МБ частной.
- Скрытая панель → `MemoryUsageTargetLevel = Low` (ICoreWebView2_19), видимая → Normal.
- Отсчёт «до сброса» не тикает, когда панель скрыта; котик и так 8 кадров/с, рисует только
  изменившийся кадр и спит при скрытом окне (S06).

## Почему не 60 МБ (честно)
Почти всё — сам WebView2 (Edge): браузерный процесс ~108 МБ рабочего набора, рендерер,
сетевой и служебные процессы. Сам tokencat.exe — 29 МБ. Убрать эти процессы можно только
отказом от WebView2 (перерисовать панель на Win32/GDI, как виджет панели задач) — это
большая переделка, делать ли её — решение после беты (B5) по отзывам.
Для сравнения: любое приложение на Electron/WebView2 в простое держит 100–300 МБ.
