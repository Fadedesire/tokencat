# Контекст проекта

## Откуда проект
Прототип v0 (папка `prototype/`) был сделан на Python + Tkinter и собран в exe через PyInstaller.
Он показывает тёмную панель поверх окон с двумя полосками (5 ч и неделя), процентом
использования и временем до сброса. В шапке оранжевая звёздочка, «Claude», точка статуса и
время обновления. На разделителе шапки сидит маленький белый пиксельный котик с idle-анимацией:
дышит, моргает, качает хвостом, иногда дёргает ухом. Обновление раз в 15 с, ПКМ — меню,
ЛКМ — перетаскивание. Пользователю результат очень понравился: внешний вид и котика
сохраняем как основу дизайна.

Главная боль прототипа: чтобы он заработал, пользователю пришлось открыть DevTools в браузере
и вручную скопировать cookie `sessionKey`. Новая версия должна обходиться без этого.

## Источник данных (неофициальный, может поменяться)
- `GET https://claude.ai/api/organizations` → список организаций. Нужна та, у которой в
  `capabilities` есть `"chat"`; берём её `uuid`.
- `GET https://claude.ai/api/organizations/{uuid}/usage` → JSON примерно такого вида:
  ```json
  {
    "five_hour":        {"utilization": 35.0, "resets_at": "2026-10-29T15:00:00+00:00"},
    "seven_day":        {"utilization": 74.0, "resets_at": "2026-11-04T10:00:00+00:00"},
    "seven_day_sonnet": {"utilization": 39.0, "resets_at": "..."} ,
    "seven_day_opus":   null,
    "extra_usage":      {"is_enabled": false, "monthly_limit": 0, "used_credits": 0.0}
  }
  ```
  `utilization` — процент израсходованного (0–100). Любое окно может быть `null`, в UI его
  просто не показываем. Набор ключей со временем меняется: неизвестные ключи игнорируем,
  отсутствие известных переживаем спокойно.
- Авторизация — cookie `sessionKey` (значение начинается с `sk-ant-sid…`) домена `.claude.ai`.
  Есть ещё `sessionKeyV3` и cookie `lastActiveOrg` (uuid активной организации).
- Заголовки, с которыми прототип работал: `Accept: application/json`,
  `Referer: https://claude.ai/`, `anthropic-client-platform: web_claude_ai`, браузерный
  User-Agent. Прямой запрос из Python без браузерного TLS-отпечатка Cloudflare мог отбивать,
  поэтому прототип использовал `curl_cffi` с `impersonate="chrome"`. Если запросы идут из
  настоящего браузерного движка (webview приложения), этой проблемы быть не должно.

### Что реально пришло 2026-10-29 (спайк S02)
- В `/usage` много новых ключей с кодовыми именами (почти все `null`) — игнорируем.
- `five_hour` / `seven_day`: `utilization` теперь целое (67, 83), плюс `*_dollars`, `locked_reason`.
- Новый массив `limits`: `{group, kind: session|weekly_all|…, percent, resets_at,
  is_active, severity: normal|warning|…, scope}`. Удобен для UI (есть готовая «серьёзность»).
  На S05 брать сначала `limits`, если его нет — `five_hour`/`seven_day`.
- `seven_day_breakdown.rows`: доля недели по продуктам (Claude Code, Чаты, Cowork, Другое),
  `display_name` уже локализован под язык аккаунта/webview.
- `spend`: кредиты сверх плана (`enabled`, `percent`, `used.amount_minor`, валюта).
- Cookie после входа: кроме `sessionKey` и `lastActiveOrg` есть `sessionKeyLC`,
  `__Host-sessionBinding`, `__Host-sessionBindingGrace`, `cf_clearance`. Нативному клиенту
  пока хватает одного `sessionKey`.

## Уроки прототипа (грабли)
1. **Cookie Claude Desktop читать нельзя.** Запущенное приложение держит файл cookies
   заблокированным. Обходить эту защиту не нужно и нельзя: это хранилище логинов. Новая
   версия не трогает чужие хранилища и логинится сама.
2. **403 от Cloudflare = почти всегда регион/VPN.** У пользователя claude.ai работает только
   через VPN. С VPN Happ всё ок; hidemy.name, похоже, пускал через туннель не все приложения
   (или не тот сервер), и программа получала 403. Нужны: понятная ошибка «claude.ai недоступен
   из вашего региона — проверьте VPN», опционально — поле для HTTP/SOCKS-прокси в настройках.
3. **Русская раскладка ломает Ctrl+V в Tkinter.** В новом стеке проверить вставку/копирование
   при русской раскладке.
4. **В PyInstaller-exe не попала библиотека** (`curl_cffi`) без `--collect-all`: проверять,
   что сборка содержит все зависимости, а не только «у меня работает из исходников».
5. Ошибки должны говорить пользователю, что делать (VPN, перелогиниться, нет сети), а
   подробности уходят в лог-файл.
6. PowerShell 5 `Tee-Object` пишет лог в UTF-16 — при чтении логов учитывать (или писать иначе).
   С S03 логи пишет `tools\run-logged.ps1` в UTF-8, папка `logs\`.
7. Удалённые инструменты Claude не могут писать в `F:\LimitCat\.github` (защищённая папка).
   Workflow лежит в `ci\build.yml`, в `.github\workflows` его кладёт `ci\install-ci.bat`.

## Подход к «входу без ключей» (кандидаты, финальный выбор на шаге S02)
- **A. Встроенное окно входа (рекомендуется).** Приложение открывает своё окно с
  `https://claude.ai/login`. Пользователь входит как обычно (Google/почта). Приложение читает
  cookie `sessionKey` из СВОЕГО webview и кладёт в системное хранилище секретов. Дальше
  запросы идут либо из скрытого webview (настоящий браузер, Cloudflare доволен), либо из
  нативного HTTP-клиента с этой cookie. Повторный вход — только когда сессия протухла (401/403
  не от Cloudflare).
- **B. Ручная вставка ключа** — оставить как запасной вариант в настройках («Продвинутое»).
- Не делать: чтение cookie браузеров пользователя, чтение файлов Claude Desktop, обход
  блокировок и защит.

## Правила и риски (важно для продаж)
- Пользовательские условия Anthropic запрещают доступ к сервису через ботов и скрипты (кроме
  API-ключа или явного разрешения) и использование их имени и логотипа в своих продуктах
  без письменного разрешения. Поэтому:
  - название и иконка свои, без «Claude» в названии и без их логотипа;
  - честная пометка «неофициальная программа, не связана с Anthropic»;
  - щадящий опрос (по умолчанию 60 с) и никакого обхода защит;
  - шаг S19 — письмо в Anthropic (marketing@anthropic.com) с вопросом о разрешении;
  - модель «бесплатно + донаты / плати сколько хочешь» безопаснее, чем жёсткая платная лицензия.
- Источник данных недокументирован и может сломаться в любой день: нужен быстрый путь
  выпустить обновление (автообновление, шаг S15).

## Конкуренты (на октябрь 2026)
Бесплатные трекеры в основном под macOS (меню-бар) или в виде расширений Chrome/VS Code.
Под Windows есть как минимум один платный, OhNine (9 € разово, Electron). Наши отличия:
нативный вид на обеих ОС, режим в панели задач Windows, вход в один клик, котик.

## Окружение пользователя
- Windows 11, два монитора, русская раскладка. Диски C/D/E/F; проект на `F:\`.
- Установлен Python (лаунчер `py`). Node.js, Rust и Visual Studio Build Tools, скорее всего,
  нет: ставим на шаге S03 (часть установщиков пользователь запускает сам).
- Доступ Claude к компьютеру: файлы на F: (чтение/запись), иногда shell на устройстве,
  управление компьютером (Проводник только кликами, без ввода текста). Сборку можно запускать
  двойным кликом по `.bat` в Проводнике.
- Мака у пользователя, возможно, нет: macOS собираем и проверяем через GitHub Actions
  (macos-runner), визуальную проверку просим сделать знакомого или используем скриншоты из CI.
- Платежи: казахстанская банковская карта, ИИН. Lemon Squeezy поддерживает выплаты на
  банковский счёт в Казахстане; Gumroad/itch.io — через PayPal или банк (проверить при
  регистрации).
