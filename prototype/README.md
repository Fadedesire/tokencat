# Прототип v0 (Python + Tkinter)

Рабочий прототип, на котором проверили идею. Только образец: внешний вид, котик
(`CAT_HEAD`, `CAT_BODY`, `CAT_TAILS`, `cat_frame`), разбор ответа `/usage`, тексты ошибок.
В новую версию код напрямую не переносится.

- `claude_limits.pyw` — исходник
- `build.bat` — сборка exe через PyInstaller
- `start.bat` — запуск без сборки
